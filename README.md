# Storyboard Stage

Build sets, pose characters and plan shots in 3D, right on your phone.

**Open it:** after GitHub Pages is switched on, the app lives at `https://<your-username>.github.io/<repository-name>/`.

## Put it on your home screen
- **iPhone (Safari):** open the address, tap **Share**, then **Add to Home Screen**.
- **Android (Chrome):** open the address, tap **⋮**, then **Install app** or **Add to Home screen**.

After the first visit it works offline. When a new version is uploaded, the app updates the next time it opens with a connection.

## Files
- `index.html`: the app
- `three.min.js`: the 3D library (three.js r128, MIT licence, see `THREE-LICENSE.txt`)
- `manifest.webmanifest`, icons: name and home-screen icon
- `sw.js`: offline support

Models and settings are stored in the phone's browser. Use **Save project** to keep a copy as a file.
